# دکتر بهانه

مولد بهانه‌ی فارسی با حال‌وهوای بامزه و دفترچه‌ای. موقعیت و لحن را انتخاب کن و یک «نسخه‌ی بهانه» با درصد باورپذیری، طرز مصرف و عوارض احتمالی بگیر.

## امکانات

- دوازده موقعیت: دیر رسیدن، تحویل ندادن پروژه، نرفتن به مهمانی، دیر جواب دادن و فراموش کردن قول
- چهار لحن: رسمی، خنده‌دار، شاعرانه و دراماتیک
- تولید فوری با قالب‌های داخلی؛ بدون نیاز به API یا ثبت‌نام
- توضیح اختیاری ماجرا برای نسخه‌ی اختصاصی در محیط سازگار Claude
- کپی و اشتراک‌گذاری متن
- تاریخچه‌ی ذخیره‌شده روی همان دستگاه
- تم روشن و تاریک خودکار
- نصب به‌صورت PWA و پوسته‌ی آفلاین
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرای محلی

نیازی به نصب وابستگی یا سرور برنامه نیست. فایل `index.html` را باز کن؛ تولید قالبی کار می‌کند.

برای تست نصب‌پذیری و Service Worker، برنامه باید از `localhost` یا HTTPS باز شود:

```powershell
py -m http.server 8080
```

سپس آدرس `http://localhost:8080` را در مرورگر باز کن.

## انتشار رایگان بدون خرید دامنه و هاست

می‌توانی از GitHub Pages استفاده کنی:

1. وارد Settings مخزن شو.
2. بخش Pages را باز کن.
3. در Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کن.
4. Branch را روی `main` و پوشه را روی `/(root)` قرار بده.
5. Save را بزن و آدرس منتشرشده را از همان صفحه بردار.

## هوش مصنوعی

نسخه‌ی فعلی برای تولید معمولی به هوش مصنوعی وابسته نیست و آفلاین هم کار می‌کند. تولید اختصاصی از قابلیت `sample` در محیط اجرای Claude استفاده می‌کند؛ این قابلیت روی هاست استاتیک مستقل تضمین‌شده نیست و برنامه در صورت نبود آن به قالب‌های داخلی برمی‌گردد.

برای اتصال به یک ارائه‌دهنده‌ی عمومی هوش مصنوعی باید API سمت سرور اضافه شود. کلید API را هرگز داخل `index.html` یا کد مرورگر قرار نده.

## ساختار فایل‌ها

- `index.html`: رابط کاربری و منطق اصلی
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: کش پوسته و حالت آفلاین
- `icon.svg`: آیکون برنامه
- `docs/PWA.md`: راهنمای تست PWA
