# دکتر بهانه

مولد بهانه‌ی فارسی. موقعیت و لحن رو انتخاب می‌کنی و یه «نسخه‌ی عذر موجه» می‌گیری، با درصد باورپذیری، طرز مصرف و عوارض احتمالی.

## قابلیت‌ها

- پنج موقعیت: دیر رسیدن، تحویل ندادن پروژه، نرفتن به مهمونی، دیر جواب دادن، فراموش کردن قول
- چهار لحن: رسمی، خنده‌دار، شاعرانه، دراماتیک
- کپی با یک کلیک و تاریخچه‌ی بهانه‌های قبلی
- تم روشن و تاریک خودکار، سازگار با موبایل
- بهانه‌ی اختصاصی بر اساس ماجرای خود کاربر (فقط وقتی صفحه کنار Claude اجرا شود، پایین را ببین)

## اجرا

بدون نصب و بدون سرور: فایل `index.html` را در مرورگر باز کن. برای انتشار هم هر هاست استاتیک (GitHub Pages، Netlify، Cloudflare Pages و…) کافی است.

## درباره‌ی هوش مصنوعی

بهانه‌ی اختصاصی از قابلیت `sample` در محیط اجرای Claude استفاده می‌کند. روی هاست مستقل این قابلیت وجود ندارد و برنامه به‌صورت خودکار به قالب‌های آماده برمی‌گردد، یعنی همه‌چیز بدون خطا کار می‌کند. برای فعال کردنش روی سایت خودتان باید یک بک‌اند کوچک بسازید که کلید API را نگه دارد و به‌جای `sample` صدا زده شود.

## فونت

فونت Vazirmatn از Google Fonts بارگذاری می‌شود. برای کاربران داخل ایران بهتر است فایل فونت کنار پروژه قرار بگیرد و با `@font-face` لود شود.
