# PWA و اجرای آفلاین

## قابلیت‌ها
- نصب روی صفحه اصلی دستگاه‌های پشتیبانی‌شده
- نمایش مستقل (standalone)
- کش پوسته‌ی اصلی برنامه
- باز شدن نسخه‌ی قبلی برنامه هنگام قطع اینترنت
- به‌روزرسانی کش هنگام انتشار نسخه جدید

## تست محلی
Service Worker فقط روی HTTPS یا localhost فعال می‌شود.
برای تست:
1. در ریشه پروژه اجرا کنید: `python -m http.server 8080`
2. آدرس `http://localhost:8080` را باز کنید.
3. از DevTools > Application وضعیت Manifest و Service Worker را بررسی کنید.
4. صفحه را یک بار بارگذاری کنید، سپس اینترنت را قطع و دوباره باز کنید.

## انتشار رایگان
می‌توان از GitHub Pages استفاده کرد:
1. وارد Settings مخزن شوید.
2. از Pages، گزینه‌ی Deploy from a branch را انتخاب کنید.
3. Branch را روی `main` و پوشه را روی `/(root)` قرار دهید.
4. آدرس Pages پس از فعال‌سازی در همان بخش نمایش داده می‌شود.

## محدودیت نسخه فعلی
تولید بهانه با قالب‌های محلی کاملاً آفلاین کار می‌کند. قابلیت نمونه‌سازی اختصاصی مبتنی بر Claude فقط در محیط Claude که قابلیت `sample` را ارائه می‌کند فعال می‌شود. برای اتصال پایدار به هر سرویس هوش مصنوعی روی وب، باید API سمت سرور اضافه شود؛ کلید API نباید در HTML یا JavaScript مرورگر قرار بگیرد.
